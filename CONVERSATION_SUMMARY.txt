### 1. **"Invalid Date" Hatası** ✅ ÇÖZÜLDÜ
**Sorun:** Notlarda tarih yerine "Invalid Date" yazıyordu.
**Neden:** `ago()` fonksiyonu Firestore Timestamp objelerini işleyemiyordu.
**Çözüm:** `src/app.js` - `ago()` fonksiyonuna `toMillis()` yardımcı fonksiyonu eklendi.
- Firestore Timestamp objeleri (`toMillis()`), protobuf format (`seconds`/`nanoseconds`), number ve string timestamp'leri destekler
- Invalid timestamp koruması eklendi (`isNaN(d.getTime())` kontrolü)
- Geçersiz timestamp'lerde "bilinmiyor" döner

**Dosya:** `src/app.js` - `ago()` fonksiyonu (satır 53-62)

### 2. "Arkadaşın" Çoğaltması Sorunu ✅ ÇÖZÜLDÜ

**Neden:** `who()` fonksiyonu fallback olarak sadece "Arkadaşın" döndürüyordu.
**Çözüm:** `who()` fonksiyonu güncellendi - anonim kullanıcılar için `Arkadaşın {ID_ilk6}` formatında unique ID veriliyor.
**Dosya:** `src/app.js` - `who()` fonksiyonu (satır 63-67)

```javascript
function who(id) {
  if (id && id === S.meId) return "Sen";
  return (S.profiles[id] && S.profiles[id].name) || "Arkadaşın " + String(id).slice(0, 6);

```

## 🔧 TEKNİK DETAYLAR (Geliştirici Notları)

### `ago()` Fonksiyonu (Güncellenmiş)
```javascript
function ago(ts) {
  if (!ts || typeof ts !== 'number' || isNaN(ts)) return "bilinmiyor";
  const ms = toMillis(ts);  // YENİ: Firestore Timestamp desteği
  if (ms === null || isNaN(ms)) return "bilinmiyor";
  const s = (Date.now() - ms) / 1000;
  // ... zaman formatlama ...
  const d = new Date(ms);
  return isNaN(d.getTime()) ? "bilinmiyor" : d.toLocaleDateString("tr-TR", { day: "numeric", month: "short" });
}

function toMillis(ts) {
  if (!ts) return null;
  if (typeof ts === 'number') return ts;
  if (ts && typeof ts.toMillis === 'function') return ts.toMillis();  // Firestore Timestamp
  if (ts && typeof ts.seconds === 'number') return ts.seconds * 1000 + Math.floor((ts.nanoseconds || 0) / 1e6);
  return null;
}
```

4. **Session validation:** Supabase Auth ile meId doğrulama
4. **MeId localStorage saklama:** `atolye-meid` key'i

### Kullanıcı Listesi Modal (`showUserListModal`)
- Mevcut kullanıcı + `S.profiles`'den diğer kullanıcılar listelenir
- Her kullanıcı için "Çıkar" butonu (kendisi hariç)
- Modal: Overlay + Header (başlık + kapat) + Body (liste)
- ESC tuşu ile kapatma, overlay tıklama ile kapatma
- ESC tuşu dinleyicisi (cleanup ile)

### `removeUser(userId)` Fonksiyonu
1. **Mevcut kullanıcıysa:** `LS_USERNAME`, `atolye-meid` silinir, `S.meId=null`
2. `S.profiles[userId]` silinir
3. Firestore: `users/{id}`, `pings/{id}` silinir (catch ile hata yutulur)
5. Toast bildirimi + modal yenilenir

### Session Persistence İyileştirmeleri (`boot()`)
- `S.meId` ve `S.username` localStorage'dan yüklenir
- `atolye-meid` localStorage'da saklanır
- Supabase Auth varsa `user?.me()` ile doğrulama
- `atolye-meid` localStorage'a yazılır (kalıcılık)
- `S.user` referansı saklanır (`S.user = user`)
